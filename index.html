云端同步设置（可选）

本地记录功能可立即使用。云端同步需要你创建自己的 Supabase 项目、配置数据库安全策略并登录邮箱；尚未配置时，记录只保存在本设备。

展开查看数据库安全策略 SQL
create table if not exists public.mental_entries (
  id text primary key,
  user_id uuid not null references auth.users(id) on delete cascade,
  entry jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.mental_entries enable row level security;
create policy "Users manage own mental entries"
on public.mental_entries for all
to authenticated
using (auth.uid() = user_id)
with check (auth.uid() = user_id);

安全提醒：不要把 service_role key 放进网页。这里只能使用 anon / publishable key，并且必须启用上方 RLS 策略。云端同步前请先确认你理解第三方云服务的数据处理方式。
